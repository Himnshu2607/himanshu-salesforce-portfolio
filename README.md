# Himanshu Kanojia — Salesforce Portfolio

Responsive single-page portfolio based on the information in my resume.

## Files
- `index.html` — portfolio
- `style.css` — responsive design

## Test locally
Open `index.html` in a browser.

## Publish on GitHub Pages
1. Create a GitHub repository, e.g. `himanshu-salesforce-portfolio`.
2. Upload `index.html`, `style.css`, and `README.md`.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**.
6. Save. GitHub will show your public Pages URL.

Before publishing, replace the placeholder LinkedIn URL in `index.html` with your real profile URL. You can also replace the GitHub placeholder with your profile/repository link.
